## D057与电脑USB

- D057是唯一新增外部正极线：降压固定5V-OUT空闲针 → 主板5V孔；原D046作为回流。D058旧USB转接负极不接。
- 本项目记录照片朝向为USB左、底部红7孔母座在下，从左到右：5V / RST / 3V3 / 5V / GND / GND / VIN；拟用第4孔5V和第5孔GND。换板或朝向不同必须重新核丝印。
- 板厂及同板电源原理图尚未唯一确认；5V孔输入能力和USB隔离不能仅靠丝印或另一款DevKitC推断。外供亮灯也不是额定/带载验收。
- **USB与D057外部5V互斥**。当前烧录和采集采用电池断开、D057降压端断开绝缘、电脑USB单供。先全断电再插拔接线。
- 主控3V3/GPIO不能接5V。驱动板5V/3V3输出不额外并到主控电源。GPIO0不接永久GND跳线。

## 动力测试边界

电机驱动厂家推荐输入5–12V，用户本次报告电源12V；3S满电12.6V不能自动当作兼容。动力支路使用合适线材/接头，不能靠普通杜邦线或D046承担电机功率回流。电机M−是H桥输出，不接公共地。

只测轮向时固定车架、四轮离地，主控USB供电且D057断开；舵机红线暂断。先确认IDLE再给合格的驱动动力，逐轮人工发命令。异常先切驱动动力。保持手、头发和线束远离轮胎。
