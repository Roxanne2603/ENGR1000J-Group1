# 快转舵、1秒/3秒档及前后回中

用户已回报上一版架空测试正常，两轮前进及左右转向均无问题；这支持进入地面短时试跑，真实带载距离/速度、轮角和刹停距离仍待测。本版按“转舵快、后轮久一点如3秒、跑前跑后回正”的要求更新，驱动幅度仍50/255，转向中位1375、左右975/1775保持。

| 串口命令（115200、换行） | 每段前进指令 | 三段累计前进指令 |
|---|---:|---:|
| START 或 START1 | 1秒 | 3秒 |
| START3 | 3秒 | 9秒 |
| STATUS | 查询当前阶段/上次所选时长/输出 | 不启动 |
| 0 / x / ! | 请求制动并锁停 | 无需回车 |

START总是默认1秒，不会因为上次用了START3而自动沿用3秒。忙时发送其他START不会改变正在执行的时长。上电IDLE、电机LOW、舵机PWM关。正常DONE后仍须明确START才能重跑；急停后先切动力再复位，不会自动恢复。

动作顺序：发送START后，先输出1375µs回中保持1秒，再倒计时3秒；直行、制动并待编码器估计低速稳定；快速转到左975µs、输出目标后等500ms、前进走短弧；同样刹停/快速转右1775µs/等500ms、前进走右短弧；最后刹停、快速回1375，保持中位1.5秒，再关输出。

转舵步进由5增至25µs，每次更新仍至少间隔20ms；实际速度由控制调度、舵机和负载决定，不称机械速度提高精确五倍。只有停着转舵，不在驱动脉冲中改变转向。正常完成保证的是1375指令及保持时间，不代表测到真实0°轮角；急停先保留最后舵向制动，避免尚在移动时突然回中。

保持输出任务独立时效80ms及单段期限；独立截止采用所选1秒/3秒，并硬上限3秒。制动至少2秒，且编码器估计速度低值稳定300ms，5秒未满足则锁停；这是辅助判据，不等于真实刹停验收。仅在PWM目标变化时写LEDC；API错误、反向或非法编码器跳变锁停。无ToF避障，不保证避墙或跑圈。

## 接线与首次落地

沿用刚才架空已确认的接线，不改GPIO：驱动B红Vin+、黑Vin−，舵机红固定5V/棕GND/橙黄GPIO14，D046/D047公共地/编码器原位。主控电脑USB供电时D057继续断开绝缘。全断电改线；先确认本次烧录成功和IDLE，再恢复电池。

由于新版转舵更快且驱动更久，先固定车架、架空用START复核一次。正常后，断动力放到空旷平地，前侧留足转弯/停车余量，USB线避开车轮并留足松弛，不让车拖拽电脑。恢复同一已核供电后先START（每段1秒）；确认起步、左右、回中和刹停情况后，再在更大空间考虑START3。1秒不起步或明显顶住时先停，不靠连续加时硬拖。

异常/接近障碍直接切动力；0/!只作补充。正常结束看DONE，不以固定总时长判断结束。先断电池再拔USB；D057这轮仍不接回。试跑回报实际动作与日志后再决定增速或连续走弯。
