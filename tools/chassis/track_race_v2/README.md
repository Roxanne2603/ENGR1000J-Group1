# A22 track_race_v2（v2.14）

ESP32-WROOM-32E 上的连续赛道试跑程序：三路 VL53L0X 前/左/右测距、后轮编码器闭环、舵机转向，自动执行一次「10 秒准备 + 1 秒回中 + 3 秒倒计时」，随后按距离目标连续行驶，最长 180 秒。**没有识别终点/计圈，不会自动重跑。**

当前版本已烧录，但**首个圆岛右侧弯道仍未通过**：v2.13 实车在右弯内墙前 `STALL_OR_ENCODER`，v2.14 加入 1.5 秒前墙左逃后尚未上赛道复核。不能把本程序当作已完成整圈或可比赛版本。

## 硬件与接线

与仓库 [WIRING](../../../docs/WIRING.md) 同一套接线：

- 前/左/右 XSH = GPIO4/13/17，SDA/SCL = GPIO21/22，地址 0x30/0x31/0x32。
- 电机 25/26/32/33，方向 +1/−1；编码器 18/19 与 34/35，方向 +1/−1。
- 舵机信号 GPIO14，中位 1375µs，左/右 575/2175µs；每 20ms 最多变 60µs。
- CPR 初值 824.2/825.7，轮周 650/3mm。
- **电脑 USB 与 D057 外部 5V 互斥。** 烧录/看日志：拔电池、断开并绝缘 D057、仅 USB；上动力前先拔 USB、接 D057/电池。

## 行为概要

| 项 | 当前实现 |
|---|---|
| 启动 | 上电/复位后 10s 准备检查 + 1s 回中 + 3s 倒计时，自动运行一次 |
| 准备门禁 | 正常双墙：前≥150mm、左右>80mm；声明左侧开口的起点：前≥250mm、右>80mm；三路模块必须初始化成功 |
| 速度 | 直道目标上限 0.20m/s；近墙/转弯 0.07–0.12m/s；PWM 上限 70/255 |
| 停车 | 前≤80mm 或预测≤50mm、侧≤65mm 或预测≤60mm 提前锁停；前≤30mm/侧≤50mm 硬底线；I2C/编码器/超速/失速/租约故障锁停 |
| 结束 | 180s 自动制动；**不识别红点终点**；人工切驱动/总电源结束 |
| 历史 | `race_history` NVS 最近 8 条，输出全 0 后写；`HISTORY` 可读；v3 格式含 `servo/turn/flags` |

### 首个圆岛（当前调试重点）

1. **左进段**：前向 <480mm 且左侧 >80mm 时，强制左转，保持 250mm 或到前向 <300mm。
2. **右绕段**：切到 `firstIslandArc`，按右侧墙 `R` 跟 250mm：
   - `turn = clip((250-R)/200, −0.6, +0.6)`；
   - 近弯只在 `R>300` 时加右：`F<280` 至少 −0.7，`F<180` 为 −0.9；
3. **前墙左逃**：`F<300 且 R<300` 时进入 `escaping`，固定 +0.6 左舵，**最少保持 1.5s**；期间再次触发则续期；1.5s 未触发才回到右绕。
4. 左侧（弯外侧）提前刹车在右绕段抑制；右侧岛壁 `SIDE_RESERVE` 与 `SIDE_HARD=50` 保留。
5. 退出右绕：行驶 3000mm 或 35s 上限。

参数是工程初值，不是 R400/R850 扫掠、带载制动或整圈验收。

## 编译与烧录

- Arduino IDE 板型 `ESP32 Dev Module`，Arduino-ESP32 **3.3.12**；本目录自带修改过的 Adafruit VL53L0X 1.2.5 驱动与 `transport_guard`/`timing_guard`，不依赖全局 Adafruit 库。
- 最近验证：程序 **349755 B** / 静态 RAM **27640 B**；COM4、115200 上传，四段写入 `Hash of data verified`；app SHA256 `3C742894E4B3EA3F258319B86C15C9A58C2C55EB97D5605E69BE8438013EA747`。
- `tests/control_checks.cpp` 是编译期断言（进弯/右绕/左逃/硬底线等），编译时执行，不是实车测试。
- 串口 115200 + 换行：`STATUS` 查询、`HISTORY` 读故障历史、`!`/`0`/`x` 软件锁停；**没有串口绕过测距检查的 RUN 命令**。

## 安全边界

软件锁停不是急停；异常先切执行器动力。USB 调试时不要接 D057 外部 5V。首次上动力先架空，再落地。手、头发、线束远离轮胎和连杆。
