# 单件MD520测试程序

step1_encoder用于单件AB相与正交计数检查，step2_isr_stress用于中断计数压力检查。以对应.ino头部命令和参数为准，不把标称CPR或示例值直接写入整车。

已确认型号记录中的尾板丝印为M+ / M− / GND / VCC / B / A；先核实物。单件手转时编码器VCC接3V3、GND共地、A接GPIO18、B接GPIO19，动力两根断开绝缘。5V输出不能直接进ESP32 GPIO。相计数0只表示未检出，不直接判退货。

双轮整车接线和符号以[当前接线](../../docs/WIRING.md)、[标定](../../docs/CALIBRATION.md)为准。计数需要记录方向、四倍频口径及非法跳变；早期文档提到的自动回写行为不能替代读取当前源码。
