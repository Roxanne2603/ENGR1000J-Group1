# 舵机测试程序

step1_servo：初次小幅人工测试；step2_steering：带前轮人工转向；step3_fast_steering：分档扩幅/回位检查。具体命令、脉宽范围和停止条件读各自.ino头部，不把其他程序的命令直接套用。

信号GPIO14，舵机红线接独立合格5V支路、棕线接该支路GND，主板与它共地。不要把舵机电源接ESP32的3V3。先核机构中心和余量、架空固定前轮，小幅开始；不能把REACHED或目标脉宽当作实际轮角。
